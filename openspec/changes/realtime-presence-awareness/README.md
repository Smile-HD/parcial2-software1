# OpenSpec Change: Realtime Presence & Visual Awareness

This change introduces Excalidraw / Figma / Google Docs style visual awareness for realtime collaboration on UML diagrams:
- User identity modal with persistent color palettes
- Live 60 FPS remote cursor tracking with floating name badges
- Remote selection halos on classes and interfaces
- First-class virtual presence and reactive activity feedback for the AI Bot
