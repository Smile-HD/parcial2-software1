# Especificación OpenSpec: Chat Colaborativo y Tutorial Amongus

Este cambio introduce el sistema de comunicación integral y onboarding amigable del modelador UML:
1. **Chat Colaborativo**: Pestaña de `Equipo` (grupal) y pestaña de `Amongus` (directo y privado con el asistente).
2. **Aislamiento por Tríada**: Clave compuesta `(diagram_id, device_id, user_name)` para evitar cruce de mensajes entre proyectos, máquinas o identidades.
3. **Limpieza Automática**: Retención TTL de 7 días.
4. **Tutorial Interactivo con Amongus**: Onboarding de 5 pasos ilustrado y animado para familiarizar a los usuarios con la herramienta.
